# Blog Editorial Index and Article Design

## Goal

Replace the conventional Blog list/article/admin styling with the approved editorial feature, scalable archive, sticky article table of contents, and accessible Markdown heading tools.

## Scope

Change only:

- Shared Blog index view.
- Six locale article routes through shared article components/helpers.
- Blog admin list.
- New-post form.
- Blog-specific localization/data/helpers/tests.
- One temporary featured image for the existing first post.

Do not change Home, UGC, Translation/SEO, Contact, navbar, or footer.

## Blog index

### Hero

- Paper background.
- Eyebrow: localized equivalent of `NOTAS · PROCESOS · IDEAS`.
- Typed localized `Blog` with permanent amaranth underscore.
- Subtitle: localized equivalent of `UN ARCHIVO DE IDEAS SOBRE CONTENIDO, IDIOMAS, CREATIVIDAD Y ESTRATEGIA.`
- One ink-alpha horizontal rule.

### Latest feature

- Select the newest post in the current locale.
- Render it once as the feature.
- Layout:
  - Left: landscape `16:10` image.
  - Right: archive number, date/tags, title, description, read link.
- Desktop columns: approximately `1.05fr 0.95fr`.
- Tight gap around `1.3rem`.
- Image, title, and read link all open the dedicated article route.
- Image scales subtly on hover.
- Add one local temporary WebP feature image to the existing Spanish post.

### Archive

- Exclude the latest feature post.
- Sort remaining current-locale posts newest-first.
- Render typographic rows:
  - Number.
  - Title.
  - Date/tags.
  - Optional image hover preview.
- Do not display sorting instructions.
- With no remaining posts, show one localized minimal row equivalent to `MÁS HISTORIAS MUY PRONTO` and `ARCHIVO EN CRECIMIENTO`.

## Article

### Header

- Back-to-blog link.
- Date and tags.
- Large title.
- Description summary.
- Contained landscape `16:9` featured image, maximum width around `850px`.

### Body

- Desktop:
  - Sticky left table of contents around `190px`.
  - Readable body around `650px`.
- Mobile:
  - Horizontal scrollable TOC chips above content.
- Render normal Markdown content through Astro.

### Table of contents

- Generate automatically from rendered Markdown H2 and H3 headings.
- H2 becomes numbered main entry: `01`, `02`, etc.
- H3 becomes nested numbering: `02.1`, `02.2`, etc.
- Use the heading IDs generated by Astro.
- Clicking scrolls to the heading.
- Active heading turns amaranth as the reader scrolls.
- Headings use `scroll-margin-top` for the fixed navbar.

### Footer navigation

- If another same-locale post exists, show next story.
- Otherwise show a link back to the Blog archive.
- Never render a dead link.

## Admin index

- Editorial `Admin · Blog / Archivo de posts` header.
- Rectangular black `+ Nuevo post` action.
- Compact post rows with number, locale, title, tags/status, and date.
- No rounded cards, pills, pastel backgrounds, or shadows.

## New-post form

- Strict paper/ink/amaranth grid form.
- Square corners.
- Preserve ES/EN/FR language restriction, duplicate-slug protection, validation, and Git Gateway publishing.
- Add featured image upload:
  - JPEG, PNG, WebP, GIF.
  - 2 MB maximum.
  - Upload asset before Markdown commit.
  - Frontmatter receives the public `/images/blog/...` path.
- Existing no-image posts use a simple ink/amaranth fallback.

### Markdown toolbar

Buttons:

- H2 Section.
- H3 Subsection.
- Bold.
- Link.

H2/H3 buttons insert valid Markdown at the current textarea selection.

### Live outline

- Parse the current textarea for H2/H3 lines.
- Show the exact nested numbered outline that will become the public TOC.
- Update while typing.
- Keep the textarea and outline in `1.35fr / 0.65fr` desktop columns.
- Mobile stacks outline below the textarea.

## Localization

Add all-six Blog keys:

- `eyebrow`
- `subtitle`
- `latestStory`
- `archive`
- `comingSoonTitle`
- `comingSoonMeta`
- `contentIndex`
- `readTime`
- `nextStory`
- `end`

Admin labels may remain ES/EN/FR according to the active admin locale.

## Motion

- Hero copy: existing clip/stagger and TypedTitle.
- Hero rule: left-to-right draw.
- Latest image/copy: opposing scroll reveals.
- Archive rows: stagger upward.
- Image hover: subtle scale.
- Article header/body: restrained reveal.
- TOC active state: amaranth/padding shift.

## Verification

1. Latest current-locale post renders once.
2. Remaining archive excludes it and stays newest-first.
3. Empty archive row appears with one post.
4. Feature image is balanced landscape and opens article.
5. Article uses generated H2/H3 TOC with correct nesting.
6. TOC links resolve to rendered heading IDs.
7. Active heading updates on scroll.
8. Admin toolbar inserts H2/H3 Markdown.
9. Live outline matches Markdown headings.
10. Featured image upload is assets-first and validates type/size.
11. Duplicate slug and locale restrictions remain.
12. Strict palette and non-rounded admin styling pass.
13. Other approved pages remain unchanged.
